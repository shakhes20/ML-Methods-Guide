# Chapter 4: Reinforcement Learning

**One word objective: Reward Maximization**

## The Big Picture

**How RL differs from supervised learning:**

| | Supervised Learning | Reinforcement Learning |
|--|--------------------|-----------------------|
| Data | Fixed labeled dataset | Generated by interaction |
| Labels | Given (y for each x) | Rewards (delayed, sparse) |
| Goal | Minimize prediction error | Maximize cumulative reward |
| Feedback | Immediate, per sample | Delayed, per episode |
| Examples | KNN, Trees, Neural nets | Chess engine, Robot, Game AI |

**Real-world examples:**
- Learning to play chess
- Robot learning to walk
- Self-driving car
- Recommendation systems

## 4.1 Markov Decision Processes (MDP)

### Components

| Symbol | Name | Meaning |
|--------|------|---------|
| S | State space | All possible situations |
| A | Action space | All possible actions (may depend on s) |
| R | Reward space | All possible rewards |
| p(s',r\|s,a) | Transition kernel | Probability of next state and reward |
| γ ∈ [0,1) | Discount factor | How much to value future rewards |

### Agent-Environment Interaction
```
Time:     t=0        t=1        t=2        t=3
State:    S₀         S₁         S₂         S₃
Action:   A₀         A₁         A₂         ...
Reward:        R₁         R₂         R₃

Trajectory: S₀, A₀, R₁, S₁, A₁, R₂, S₂, A₂, R₃, ...
```

### The Markov Property

**Definition:**
```
P(S_{t+1}=s', R_{t+1}=r | Sₜ, Aₜ, S_{t-1}, A_{t-1},...,S₀)
= P(S_{t+1}=s', R_{t+1}=r | Sₜ, Aₜ)
```

**In plain English:** the future depends ONLY on the current state and action — not the history.

**Why we need it:**
1. Without it: state space grows with time → infinite parameters
2. With it: current state Sₜ is sufficient statistic for future
3. Enables Bellman equation decomposition
4. Makes dynamic programming tractable

### Transition Probabilities
```
p(s',r|s,a) := P(S_{t+1}=s', R_{t+1}=r | Aₜ=a, Sₜ=s)

Marginal state transition:  p(s'|s,a) = Σ_r p(s',r|s,a)

Expected reward:  r(s,a) = Σ_{s',r} r · p(s',r|s,a)
```

### Example: Recycling Robot
```
States:  S = {high battery, low battery}
Actions: A(high) = {search, wait}
         A(low)  = {search, wait, recharge}
Rewards: positive for finding cans, -3 for battery depletion

Transition example:
   From high, search → stays high with prob α
                     → drops to low with prob 1-α
```

## Policies and Value Functions

### Policy
```
Deterministic: π: S → A
Stochastic:    π(a|s) = P(Aₜ=a | Sₜ=s)
```

### State-Value Function
```
V^π(s) = E_π[ Σ_{k=0}^∞ γᵏ R_{t+k+1} | Sₜ=s ]
```
Expected cumulative discounted reward starting from state s, following π.

### Action-Value Function
```
Q^π(s,a) = E_π[ Σ_{k=0}^∞ γᵏ R_{t+k+1} | Sₜ=s, Aₜ=a ]
```
Expected return starting from s, taking action a, then following π.

### Bellman Equation for V^π
```
V^π(s) = Σ_a π(a|s) Σ_{s',r} p(s',r|s,a) [r + γ V^π(s')]
          ↑           ↑                      ↑       ↑
      over actions  transition          immediate  discounted
                    probability          reward   future value
```

**Derivation sketch:**
1. Start from definition
2. Peel off first reward
3. Recognize recursive structure
4. Expand expectation over actions and transitions

### Optimal Value Function
```
V*(s) = max_π V^π(s)   (best possible value)

Bellman Optimality Equation:
V*(s) = max_a Σ_{s',r} p(s',r|s,a) [r + γ V*(s')]

Optimal policy:
π*(s) = argmax_a Σ_{s',r} p(s',r|s,a) [r + γ V*(s')]
```

## 4.2 Dynamic Programming

**Requires:** full knowledge of p(s',r|s,a) — the model.

### Policy Evaluation
Compute V^π for a given policy π:
```
V_{k+1}(s) ← Σ_a π(a|s) Σ_{s',r} p(s',r|s,a) [r + γ Vₖ(s')]

Repeat until: max_s |V_{k+1}(s) - Vₖ(s)| < ε
```

### Policy Iteration
```
Initialize: random policy π₀

Repeat:
   EVALUATE:  compute V^πₖ (full policy evaluation)
   IMPROVE:   π_{k+1}(s) = argmax_a Σ_{s',r} p(s',r|s,a) [r + γ V^πₖ(s')]

Until: π_{k+1} = πₖ  → π* found
```

**Convergence:** finite steps — at most |A|^|S| policies to check.

### Value Iteration
```
Initialize: V₀(s) = 0  for all s

Repeat:
   V_{k+1}(s) = max_a Σ_{s',r} p(s',r|s,a) [r + γ Vₖ(s')]

Until: max_s |V_{k+1}(s) - Vₖ(s)| < ε

Extract policy:
   π*(s) = argmax_a Σ_{s',r} p(s',r|s,a) [r + γ V*(s')]
```

### Comparison

| | Policy Iteration | Value Iteration |
|--|-----------------|----------------|
| Updates | Policy + value function | Value function only |
| Inner loop | Full policy evaluation | Single Bellman backup |
| Convergence | Exact, finite steps | Approximate, iterative |
| Cost per step | Higher | Lower |

## 4.3 Temporal-Difference Learning

**Problem with DP:** requires knowing p(s',r|s,a) — often unknown in practice.

**TD Solution:** learn from experience — interact with environment, observe transitions.

### TD Error
```
δₜ = R_{t+1} + γ V(S_{t+1}) - V(Sₜ)
     ↑                        ↑
   TD target              current estimate
```

**Intuition:**
```
δₜ > 0: reality was BETTER than expected → increase V(Sₜ)
δₜ < 0: reality was WORSE than expected  → decrease V(Sₜ)
δₜ = 0: perfectly calibrated → no update
```

### TD(0) Update Rule
```
V(Sₜ) ← V(Sₜ) + α · δₜ
       = V(Sₜ) + α · [R_{t+1} + γ V(S_{t+1}) - V(Sₜ)]
```

**α = learning rate** (step size), typically small (0.01 to 0.1).

### SARSA — On-Policy TD Control
```
Q(Sₜ, Aₜ) ← Q(Sₜ, Aₜ) + α [R_{t+1} + γ Q(S_{t+1}, A_{t+1}) - Q(Sₜ, Aₜ)]

Name: (S, A, R, S', A') — uses actual next action
Type: On-policy — learns about the policy being followed
```

### Q-Learning — Off-Policy TD Control
```
Q(Sₜ, Aₜ) ← Q(Sₜ, Aₜ) + α [R_{t+1} + γ max_a Q(S_{t+1}, a) - Q(Sₜ, Aₜ)]

Key difference: max_a — uses BEST possible next action
Type: Off-policy — learns optimal policy regardless of behavior
```

### SARSA vs Q-Learning

| | SARSA | Q-Learning |
|--|-------|-----------|
| Next action used | Actual A_{t+1} | Best possible max_a |
| Policy type | On-policy | Off-policy |
| Learns | Current policy value | Optimal policy value |
| Behavior | Conservative | Aggressive |
| Good for | Safe exploration | Finding optimal policy |

**Cliff example:**
```
Safe path: -1 per step, reliable
Cliff path: +5 if lucky, -100 if fall

SARSA:      considers risk of falling → takes safe path
Q-Learning: assumes optimal behavior → may risk cliff path
```

## Summary — All of RL

```
MDP = (S, A, R, p, γ)
  Markov property → current state is sufficient for future

POLICY π: how agent chooses actions
VALUE V^π(s): expected return from state s under π
BELLMAN: V^π(s) = Σ_a π(a|s) Σ_{s',r} p(s',r|s,a)[r + γV^π(s')]

DYNAMIC PROGRAMMING (know model p):
  Policy Iteration  → evaluate + improve → exact π*
  Value Iteration   → backup until convergence → approximate π*

TEMPORAL DIFFERENCE (don't know model p):
  TD error δₜ = R_{t+1} + γV(S_{t+1}) - V(Sₜ)
  SARSA      → on-policy, uses actual next action
  Q-Learning → off-policy, uses best next action → learns π*

KEY PARAMETERS:
  γ: discount factor — how much future matters (0=myopic, 1=far-sighted)
  α: learning rate — how fast to update estimates
  ε: exploration rate — how often to try random actions
```
